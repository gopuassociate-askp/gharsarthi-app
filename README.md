# Ghar Sarthi app

The family app for Ghar Sarthi: Sneha, a caring voice in Hindi, calls elders every day. Families sign up, see their service status, payments and medicines here.

This repository holds only the app's public files. It is built from the private Ghar Sarthi project (`app/`, `node tools/build-app.js`); do not edit these files by hand.
